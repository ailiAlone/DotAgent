## Project Overview
A 2D arcade-style shooter built in Godot 4.5, using a scene-composition architecture with an autoloaded global manager. The main entry point is `res://scenes/main.tscn`, which hosts the game controller (`res://scripts/game.gd`) and the HUD. `res://scripts/game_manager.gd` is registered as an autoload in `project.godot` and acts as a global state / spawn coordinator.

## System Modules
| Module | Responsibility | Key Files | Key Functions/Signals |
|--------|---------------|-----------|----------------------|
| Entry / Main Scene | Root scene that runs the game loop; instantiates/hosts the Game Controller and HUD. | `res://scenes/main.tscn` | `_ready` |
| Game Controller | Spawns waves, tracks score/lives, handles game-over and restart, wires player/enemy/bullet events. | `res://scripts/game.gd`, `res://scenes/game.tscn` | `new_game`, `game_over`, `_spawn_enemy`, `_on_player_died`, `_on_enemy_died`; signals `score_changed`, `lives_changed`, `game_over` |
| Autoload GameManager | Global game state, group-based self-lookup, spawn timer, and HUD scene reference. | `res://scripts/game_manager.gd`, `res://project.godot` | `_ready`, `spawn_enemy`/`_on_spawn_timer_timeout`, `add_score`, `set_lives`, `update_hud`; constants `GAME_MANAGER_GROUP`, `SPAWN_INTERVAL`; preloads `hud_scene` |
| Player | Movement, shooting, collision/health, and death notification. | `res://scripts/player.gd`, `res://scenes/player.tscn` (inferred) | `_physics_process`, `shoot`, `_on_body_entered`, `take_damage`, `start`; signals `bullet_fired`, `died` |
| Enemies | Spawn movement, damaging the player, dying when hit by bullets. | `res://scripts/enemy.gd`, `res://scenes/enemy.tscn` | `_ready`, `_physics_process`, `take_damage`, `die`; signals `enemy_died`, `player_hit` |
| Projectiles | Forward-traveling bullets with screen-exit cleanup and hit detection. | `res://scripts/bullet.gd`, `res://scenes/bullet.tscn` | `_physics_process`, `_on_area_entered`/`_on_body_entered`, `_on_screen_exited` |

| UI / HUD | Displays score/lives, shows messages/game-over, and emits restart requests. | `res://scripts/hud.gd`, `res://scenes/hud.tscn` | `update_score`, `update_lives`, `show_message`, `show_game_over`, `_on_start_button_pressed`; signal `start_game` |

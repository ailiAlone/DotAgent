## 星海猎手 (Star Hunter) — 项目全景

**引擎与入口**
- Godot 4.5，主场景 `res://scenes/main.tscn` / `scripts/main.gd`。
- 自动确保 `GameManager` 和 `AudioManager` 单例存在，并启动主菜单。

**Autoload 单例**
- `GameManager`：分数、最高分、生命、连击、分数倍率，最高分存 `user://high_score.save`。
- `AudioManager`：程序化生成全部 SFX 和音乐，常驻运行。
- `SettingsManager`：读写 `user://settings.cfg` 管理音量/难度，但当前无 UI 连接。

**核心玩法循环**
- `Menu` → `Game` → `GameOver` / 返回菜单。
- `Game` 统筹玩家、敌人生成、波次、道具、小行星、特效、HUD、暂停菜单。
- 每 30 秒自动推进波次；每 5 波触发 Boss 战。

**玩家系统**
- 文件：`scripts/player.gd` / `scenes/player.tscn`。
- 控制：WASD/方向键移动，SPACE/J 射击，L 冲刺，SHIFT 散射。
- 机制：5 HP、护盾、快速射击、Dash、武器等级 0-4（击杀积累经验升级）。
- 信号：`died`, `shoot`, `shoot_spread`, `hit`, `powerup_collected`, `weapon_level_changed`。

**敌人系统**
- 文件：`scripts/enemy.gd` / `scenes/enemy.tscn`。
- 6 种类型：SCOUT、FIGHTER、TANK、BOMBER、SWEEPER、CARRIER。
- 支持编队生成、精英敌人、Carrier 召唤小弟。
- Boss：`scripts/boss.gd` / `scenes/boss.tscn`，3 阶段弹幕，每 5 波出现。

**其他子系统**
- 子弹：`bullet.gd` / `bullet_pooled.gd`（池化版本未启用）。
- 道具：`powerup.gd` — 回血、速射、护盾、炸弹、双倍分数。
- 小行星：`asteroid.gd` — 随机多边形，可碎裂。
- 特效：`explosion.gd`、`hit_spark.gd`、`screen_flash.gd`。
- HUD：`hud.gd` — 分数、最高分、生命、连击、波次/武器等级、道具提示。
- 星空背景：`star_field.gd` — 视差星空 + 阶段调色板切换。

2. `scenes/settings_menu.tscn` 没有脚本，设置菜单未接入 `SettingsManager`。
3. `scripts/pool.gd` / `bullet_pooled.gd` 存在但未被使用，当前仍直接实例化并销毁。
4. `player_trail.gd` 的 `tick/reset` 接口没有被 `player.gd` 实际驱动。
5. 输入配置部分分散：`project.godot` 中未定义 `alt_shoot` 和 `dash`，由 `main.gd` 运行时兜底注册。

## Project Overview
A 2D arcade/space shooter (Asteroids-style) built in Godot 4. Uses a Node/Node2D scene tree with **singleton/autoload pattern** for cross-cutting concerns (weapons, audio), and per-entity scripts attached to scene nodes. The main entry point is the default scene configured in `res://project.godot`.

## System Modules
| Module | Responsibility | Key Files | Key Functions/Signals |
|--------|---------------|-----------|----------------------|
| Weapon System | Autoload singleton tracking the player's current weapon type and providing shared weapon data (PISTOL, SPREAD, LASER) | `res://scripts/weapon_system.gd` | `WeaponType` enum, `WEAPON_*` constants, `get_weapon_data()`, `set_weapon_type()` |

| Projectile | Bullet behavior, collision, and lifetime | `res://scripts/bullet.gd` | `_on_body_entered` / collision handling |
| Powerups | Collectible pickups that alter the active weapon | `res://scripts/powerup.gd` | `area_entered` / pickup signal |
| Asteroids | Enemy obstacle/target entities | `res://scripts/asteroid.gd` | `destroy()`, `split()` |
| Audio | Autoload singleton managing sound/music playback | `res://scripts/audio_manager.gd` | `play_sound()`, `play_music()` |

- **Player** reads from the `WeaponSystem` autoload to determine which weapon type to fire.
- **Powerups** call into `WeaponSystem` to change the current weapon (e.g., `set_weapon_type()`).
- **Player** instantiates `Bullet` scene nodes; `Bullet` handles collisions with `Asteroid`.
- **AudioManager** autoload is invoked by gameplay systems (Player, Bullet, Asteroid, Powerup) for SFX/music.
- `WeaponSystem` is registered as an autoload in `res://project.godot`, so any scene can access it directly.

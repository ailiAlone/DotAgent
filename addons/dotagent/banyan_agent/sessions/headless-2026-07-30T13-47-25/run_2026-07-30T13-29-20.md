### Key Mechanisms
- `Powerup` extends `Node2D` (no Area2D/CollisionShape2D), matching the existing `enemy.gd`/`bullet.gd` pattern so `game.gd` can perform manual distance-based collection checks against the player.
- `enum Type { HEAL, RAPID_FIRE, SHIELD, BOMB }`.
- `DROP_SPEED = 80.0` downward movement in `_process(delta)`.
- `SIZE = 12.0` used for both the drawn circle radius and off-screen culling margin.
- `_draw()` renders a colored circle per type:
  - HEAL → green
  - RAPID_FIRE → orange
  - SHIELD → blue
  - BOMB → purple
- Off-screen cleanup: `queue_free()` once the powerup falls below viewport + `SIZE`.

### Public Interface
- `@export var powerup_type: Type = Type.HEAL` — configurable per instance.
- `const SIZE: float = 12.0` — exposed so `game.gd` can use it for distance checks.
- Group membership: `"powerup"` (on scene root).

### Dependencies
- No script dependencies on other systems.
- Expects `game.gd` to instantiate `powerup.tscn`, optionally set `powerup_type`, and detect collection via distance check using `player.position` and `Powerup.SIZE`.
